# JLPT word lists

`n5.csv` to `n1.csv` list the words of each JLPT level with the number of their JMdict entry
(`jmdict_seq`). `scripts/build-dictionary.mjs` reads them to give dictionary entries their level
and to build the quiz's JLPT word sets.

The files are copied unchanged from
[stephenmk/yomitan-jlpt-vocab](https://github.com/stephenmk/yomitan-jlpt-vocab) (`original_data/`),
which is licensed CC BY-SA 4.0. The lists themselves come from
[Jonathan Waller's JLPT resources](https://www.tanos.co.uk/jlpt/), shared under a Creative Commons
BY licence. There are no official JLPT word lists; these are a well-informed guess.
